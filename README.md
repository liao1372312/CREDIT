# CREDIT

Research code and bundled data for *CREDIT: Retrieval-Aware Causal Memory Maintenance for Evolving Web Service Agents*.

## Repository contents

- `credit/v3/` — core CREDIT code.
- `credit/paper_7944_*.py` — paper protocol, model, and run code.
- `datasets/` — bundled data, including historical Retail and Airline memory pools.
